# Contratos de operación: UC02

> **Versión:** `0.1.0`

## 1. Operaciones del sistema

En el marco de la iteración **E1** (escenario `UC02-BasicMemory`), se
especifican los contratos para las tres operaciones del sistema (DSS) que
gobiernan la ejecución en memoria y mitigan el riesgo técnico **R1**:

1. **`startSimulation(mode: ExecutionMode)`** [Comando]: Inicializa el entorno
   de ejecución, crea el ámbito de memoria global y posiciona el cursor en el
   primer bloque ejecutable.
2. **`executeNextStep()`** [Comando]: Aplica la semántica de la instrucción del
   bloque activo, muta el estado de las celdas de memoria, registra la traza y
   avanza el cursor de control.
3. **`getMemoryState(stepNumber?: Integer): EstadoDeMemoria`** [Consulta]:
   Operación de lectura pura (principio CQS) que expone el estado observable de
   la memoria sin efectos colaterales.

## 2. Especificación de contratos

### Contrato CO1: `startSimulation`

```yaml
Operación:          startSimulation(mode: ExecutionMode)
Referencias:        UC02 (Flujo básico, pasos 1-3)
Precondiciones:
  - Existe un EspacioDeTrabajo abierto con un ProgramaPrincipal estructurado.
  - El ProgramaPrincipal es sintácticamente válido según el PerfilConfiguracion activo.
  - No existe una Simulacion activa en ejecución en el EspacioDeTrabajo.

Postcondiciones:
  Creación de instancias:
    - Se creó una instancia 'sim' de Simulacion.
    - Se creó una instancia 'pe' de PruebaDeEscritorio.
    - Se creó una instancia 'amb' de AmbitoDeMemoria.
    - Se creó una instancia 'est' de EstadoDeMemoria.
    - Se creó una instancia 'paso0' de PasoDeSimulacion.

  Formación de asociaciones:
    - 'sim' se asoció con el EspacioDeTrabajo actual (relación 'simula').
    - 'pe' se asoció con 'sim' (relación 'proyectaTraza').
    - 'amb' se asoció con el ProgramaPrincipal (relación 'contextoDe').
    - 'est' se asoció con 'amb' (relación 'ambitosActivos').
    - 'paso0' se asoció con 'sim' (relación 'trazaPasos').
    - 'paso0' se asoció con 'est' (relación 'memoriaResultante').
    - 'paso0' se asoció con el primer Bloque de la Secuencia del ProgramaPrincipal (relación 'bloqueActivo').

  Modificación de atributos:
    - 'sim.modo' se fijó en el valor del parámetro 'mode' ('continuo' | 'pasoAPaso').
    - 'amb.nombreAmbito' se inicializó con "global".
    - 'paso0.numeroDePaso' se fijó en 0.
    - 'sim.estado' se fijó en 'enEjecucion'.
```

### Contrato CO2: `executeNextStep`

```yaml
Operación:          executeNextStep()
Referencias:        UC02 (Flujo básico, pasos 4-7; extensiones 5a, 5b, 5c, 5g)
Precondiciones:
  - Existe una Simulacion activa 'sim' en el EspacioDeTrabajo.
  - 'sim' no ha finalizado ni se encuentra en estado de error de ejecución.
  - Existe un PasoDeSimulacion previo ('pasoAnterior') con un Bloque activo ('bloqueActual') asignado.

Postcondiciones:
  Creación de instancias:
    - Se creó una instancia 'nuevoPaso' de PasoDeSimulacion.
    - Se creó una instancia 'nuevoEstado' de EstadoDeMemoria.
    - Si 'bloqueActual' es una Asignacion a una variable no existente en el AmbitoDeMemoria activo:
        - Se creó una instancia 'vMem' de VariableEnMemoria.
        - Se creó una instancia 'cMem' de CeldaDeMemoria.
    - Si 'bloqueActual' es una Asignacion o Entrada:
        - Se creó una instancia 'val' de Valor (ValorEscalar o ReferenciaMemoria).
    - Si 'bloqueActual' es una Entrada o Salida:
        - Se creó una instancia 'evt' de EventoES.

  Formación de asociaciones:
    - 'nuevoPaso' se asoció con 'sim' (incorporado a 'trazaPasos').
    - 'nuevoPaso' se asoció con 'nuevoEstado' (relación 'memoriaResultante').
    - 'nuevoPaso' se asoció con 'bloqueActual' como el bloque ejecutado.
    - 'nuevoEstado' se asoció con los AmbitoDeMemoria actualizados tras la ejecución del paso (relación 'ambitosActivos').
    - Si se creó 'vMem':
        - 'vMem' se asoció con la Variable de origen (relación 'origenVariable').
        - 'vMem' se asoció con 'cMem' (relación 'contieneCeldas').
        - 'vMem' se asoció con el AmbitoDeMemoria activo (relación 'variablesVisibles').
    - Si 'bloqueActual' es una Asignacion o Entrada:
        - La CeldaDeMemoria receptora se asoció con 'val' (relación 'almacena').
    - Si se creó 'evt':
        - 'evt' se asoció con 'nuevoPaso' (relación 'produce').
    - Si el flujo secuencial no ha finalizado:
        - 'nuevoPaso' se asoció con el siguiente Bloque a ejecutar según las reglas N-S (relación 'bloqueActivo').

  Modificación de atributos:
    - 'nuevoPaso.numeroDePaso' se fijó en 'pasoAnterior.numeroDePaso + 1'.
    - Si 'bloqueActual' es una Entrada:
        - 'evt.tipo' se fijó en 'entrada'.
        - 'evt.contenido' se fijó con la representación textual del dato ingresado.
    - Si 'bloqueActual' es una Salida:
        - 'evt.tipo' se fijó en 'salida'.
        - 'evt.contenido' se fijó con la representación textual del valor evaluado.
    - Si 'bloqueActual' fue el último bloque ejecutable y no restan instrucciones pendientes:
        - 'sim.estado' pasó a 'finalizada'.
```

### Contrato CO3: `getMemoryState`

```yaml
Operación:          getMemoryState(stepNumber?: Integer): EstadoDeMemoria
Referencias:        UC02 (Flujo básico, pasos 4 y 8; Separación Modelo-Vista y principio CQS)
Precondiciones:
  - Existe una Simulacion inicializada o en ejecución en el EspacioDeTrabajo.
  - Si se proporciona 'stepNumber', este debe ser mayor o igual a 0 y menor o igual al último 'numeroDePaso' registrado en 'sim.trazaPasos'.

Postcondiciones:
  - Ninguna instancia de clase conceptual fue creada ni destruida.
  - Ninguna asociación entre objetos fue modificada ni destruida.
  - Ningún atributo de los objetos del dominio fue alterado.
  - Se retornó el EstadoDeMemoria correspondiente al paso consultado (o al último paso registrado si 'stepNumber' no fue especificado), incluyendo sus AmbitoDeMemoria, VariableEnMemoria y CeldaDeMemoria asociadas.
```

### Contrato CO4: `stopSimulation`

```yml
Operación:          stopSimulation()
Referencias:        UC02 (Extensión *b)
Precondiciones:
  - Existe una Simulacion activa 'sim' en el EspacioDeTrabajo.
  - 'sim.estado' es 'enEjecucion' o 'pausada'.

Postcondiciones:
  - 'sim.estado' pasó a 'detenida'.
  - Se preservó la traza registrada en 'sim.trazaPasos' para consulta de la PruebaDeEscritorio.
```
